# Spring Boot Mastery

Este é um projeto desenvolvido para estudos avançados de Spring Boot, incluindo o uso de JPA, PostgreSQL, H2 Database, e outras ferramentas do ecossistema Spring.

## Tecnologias Utilizadas

- **Java 17**
- **Spring Boot**
- **Spring Data JPA**
- **PostgreSQL**
- **H2 Database**
- **Lombok**
- **Maven**

## Funcionalidades

- Configuração de múltiplos bancos de dados (H2 e PostgreSQL).
- Uso de JPA para persistência de dados.
- Desenvolvimento de APIs REST.
- Testes automatizados com Spring Boot Starter Test.
